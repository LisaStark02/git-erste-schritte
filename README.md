# Git – erste Schritte

Dieses Repository habe ich im Modul Web IT angelegt, um die Grundlagen von Git und GitHub zu üben.
Ich habe gelernt, wie man Änderungen mit Commits speichert und über Branches und Pull Requests zusammenführt.

## Wichtige Git-Begriffe

- **Repository:** Projektablage mit allen Dateien und der kompletten Änderungshistorie
- **Commit:** gespeicherter Schnappschuss zusammengehöriger Änderungen mit Nachricht
- **Branch:** eigene Entwicklungslinie, auf der man unabhängig arbeiten kann
- **Pull Request:** Anfrage, Änderungen aus einem Branch in einen anderen zu übernehmen
